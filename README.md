# Corp-Quest
Jogo Educativo para Sala de Aula Invertida Projeto voltado ao desenvolvimento de um jogo interativo projetado para engajar estudantes e reforçar o aprendizado em dinâmicas de metodologia ativa (flipped classroom). O objetivo é transformar o estudo prévio e a fixação de conteúdos em uma experiência lúdica e colaborativa.
